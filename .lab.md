# .lab — o que o Instagram exige na prática

Achados de teste contra a API real, com conta logada. Cada linha aqui custou uma
requisição; não repita os experimentos à toa.

## Requisitos por tipo de conteúdo

| Conteúdo | Precisa seguir o perfil? | Rota que funciona | Verificado |
|---|---|---|---|
| Perfil | não | `GET /api/v1/users/web_profile_info/?username=` | 16/08/2026 |
| Reels | não | `GET /api/v1/feed/user/{id}/` → filtra `product_type: clips` | 16/08/2026 |
| Posts / vídeos | não | `GET /api/v1/feed/user/{id}/` | 16/08/2026 |
| **Stories** | **SIM** | `GET /api/v1/feed/reels_media/?reel_ids={id}` | 16/08/2026 |
| Mídia por URL | — | **nenhuma rota funciona com sessão web** | 16/08/2026 |

## Rotas que NÃO funcionam com sessão web

- `POST /api/v1/clips/user/` → `401 require_login`. Reels vêm pelo feed.
- `GET /api/v1/media/{id}/info/` → `302` para `/accounts/login/`. É rota do app
  mobile; cookie web não serve.
- Páginas HTML (`/p/`, `/reel/`, `/stories/`) → `302` para a raiz com a sessão, e
  shell de JS vazio (~608 KB, sem dados) sem a sessão.

## Stories: a pegadinha principal

`reels_media` responde **200 OK com `{"reels":{}}`** quando a conta logada não
segue o perfil alvo. Não é erro, não é sessão inválida, não é story expirado —
é vazio silencioso.

Testado com `@ocomandante`: público, verificado, 1,4M seguidores, story de 9h de
idade (dentro das 24h). Resultado: vazio, porque `iter_bike` não segue.

**Conclusão:** para monitorar stories, a conta precisa seguir cada alvo.

## Rate limit

- Dispara com poucas dezenas de requisições em minutos.
- Resposta: `401` com `require_login: true` **mas** mensagem "Aguarde alguns
  minutos antes de tentar novamente". Não confundir com sessão morta.
- Dura de minutos a horas. Insistir agrava.
- Ritmo seguro em teste: 4–9s entre requisições, orçamento fechado por execução.

## Restrições observadas na sessão de teste

A sessão do `iter_bike` funciona na **API** mas leva `302` em **qualquer página
HTML**. Pode ser específico dessa conta. Efeito prático: não dá para cair no
plano B de raspar o HTML.

## Transcrição

- Modelo `ggml-base` (142 MB) transcreveu reel em **português como inglês**
  ("Don't lose that"). Para pt-BR: `large-v3-turbo` + `Language: "pt"` fixo.
- 10s de vídeo → 9s de transcrição com `base` em container ARM64 sem GPU.
- whisper.cpp não compila com gcc 12 em arm64 (intrínsecos NEON fp16); usar clang.

## Pipeline validado ponta a ponta

16/08/2026, dentro de container OrbStack, 2 requisições:

```
perfil → reels → download CDN (1 MB) → ffmpeg → whisper (9s) → chunk → payload
```

Download da CDN **não usa cookie** e não conta no rate limit da conta.
